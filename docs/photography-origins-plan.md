# 《光之书写》——摄影的起源 · 视频方案

## 1. 概览

| 项目 | 设定 |
|---|---|
| 片名（暂定） | 光之书写 / WRITING WITH LIGHT |
| 规格 | 1920×1080，30fps，约 72 秒（2160 帧） |
| 一句话 | 从墨子的小孔到手机里的两亿像素，讲人类如何学会"留住光"。 |
| 叙事主线 | 按时间推进：公元前 400 年 → 1727 → 1827 → 1838 → 1839 → 1861 → 1878 → 1888 → 1975 → 今天 |
| 情绪曲线 | 黑暗与好奇 → 第一张照片成像（高潮一） → 1839 镜头（视觉中心） → 人人都能拍 → 回到那束光 |
| 署名 | `@一次成像` |
| 照片策略 | 真实公版照片只在关键时刻出现，并且都通过粒子或颗粒成像入场；其余画面程序化生成 |

### 从参考片继承的手法

| 参考片（Opus 5.5） | 本片 |
|---|---|
| 宇宙尺度的连续缩放 | 时间轴上的连续推进，章与章之间用匹配转场（小孔 → 颗粒 → 照片 → 镜头 → 像素） |
| 光行时间计数器 | 曝光时间计数器：≥ 28 800 s（8 小时）→ ≈ 300 s → ≈ 20 s → < 1/2000 s |
| `dτ/dt` 按物理公式计算 | 光圈 f 值与曝光时间 t ∝ N²（Chevalier f/14 → Petzval f/3.6） |
| 黑洞 + 3D 环形文字 + 穿越 | 1839 黄铜镜头 + 3D 环形文字 "φῶς + γραφή" + 穿过镜片组 |
| 星座连线扩散成网络 | 一张快照裂变成成千上万张，再量化成像素马赛克 |
| 粒子聚合成 Claude 星芒 | 粒子聚合成光圈叶片图形 |
| 闪白硬切 → 奶白落版 | 相机闪光硬切 → 相纸白落版（全片唯一硬切） |
| 陶土橙强调色 | 暗房安全灯红 |
| 电影遮幅（落版时去掉） | 同样处理 |

## 2. 分镜脚本

时间为成片时间码；相邻两章重叠 10–15 帧做转场。

### 01 CAMERA OBSCURA · 小孔成像 ｜ 0:00–0:06
- 字幕：两千四百年前，墨子看见光穿过小孔，把世界倒映在墙上。
  *Twenty-four centuries ago, Mozi saw light pass through a pinhole and cast the world upside down.*
- 画面：全黑中，一束细光从小孔射入，光束里漂着尘埃粒子（丁达尔效应）。光线在孔处交叉，对面墙上慢慢浮现倒立的塔影。光路按真实小孔成像几何绘制：物点、小孔、像点三点共线。
- 标注：`MOZI · 墨子 · c. 400 BCE` / `景到，在午有端 ——《墨经》`
- 转场：镜头推进墙上的倒影，直到看见组成它的颗粒。

### 02 SILVER · 银盐 ｜ 0:06–0:11
- 字幕：影像总会消散——直到人们发现，银会被光染黑。
  *The image always faded — until we found that silver darkens in light.*
- 画面：倒影闪烁、消散；镜头推进成银盐晶格点阵，被光照到的颗粒由亮转暗。
- 标注：`2AgCl + hν → 2Ag + Cl₂` / `J. H. SCHULZE · 1727`
- 转场：变暗的颗粒开始流动、聚集。

### 03 HELIOGRAPHY · 日光刻印 ｜ 0:11–0:18
- 字幕：窗外的屋顶，在锡板上停留了至少八个小时。
  *The rooftops outside a window lingered on a pewter plate for at least eight hours.*
- 画面：颗粒飞入就位，聚合成《窗外景色》（真实照片转点云）。**音乐 drop 对在成像完成的一刻（≈ 0:12.5）**。画面上方一道太阳轨迹弧线从左扫到右，建筑阴影随之翻转，交代为什么这张照片里两侧墙面都被照亮。
- 计数器首次出现（右上）：`EXPOSURE · 曝光时间` ≥ `28 800` `SECONDS · 秒`
- 标注：`POINT DE VUE DU GRAS · NIÉPCE` / `BITUMEN ON PEWTER · c. 1827` / `现存最早的照片`
- 转场：锡板旋转，表面变成银镜般的反光。

### 04 DAGUERREOTYPE · 银版 ｜ 0:18–0:25
- 字幕：巴黎街头车马不息，只有一个擦鞋的人站得够久，留在了画面里。
  *On a busy Paris street, only a man having his boots shined stood still long enough to remain.*
- 画面：林荫大道上，静态建筑之间有大量行人、马车粒子拖尾穿过。随着曝光推进，移动的物体越来越淡，最后只剩擦鞋的人，被圆圈标出。结尾利用银版特有的"倾斜时正负像翻转"出场。
- 计数器：`28 800 → ≈ 600`（对数插值）
- 标注：`BOULEVARD DU TEMPLE · DAGUERRE · 1838` / `THE FIRST PERSON EVER PHOTOGRAPHED · 第一个被拍下的人`
- 转场：镜头后拉，银版原来是相机里的成像面；继续后拉，穿出镜头。

### 05 1839 · PHOTOGRAPHY · 摄影 ｜ 0:25–0:34（视觉中心，对应参考片的黑洞）
- 字幕：1839 年，它有了名字：用光书写。
  *In 1839, it was given a name: writing with light.*
- 画面：画面中心是一枚 3D 黄铜镜头（多层镜片同心环 + 光圈叶片），四周光线粒子被吸入镜头。环形文字 `PHOTOGRAPHY — φῶς, LIGHT · γραφή, WRITING — J. HERSCHEL · 1839 —` 在 3D 空间里绕镜头旋转，转到背面时呈镜像。最后镜头穿过镜片组，镜片反射的光斑依次掠过，光圈叶片张开，画面转白。
- HUD（左上）：`APERTURE · 光圈` 从 `f/14`（Chevalier）变到 `f/3.6`（Petzval, 1841），曝光时间按 t ∝ N² 实时计算：`300 → ≈ 20 s`。人像摄影从此变得可行。
- 标注：`PETZVAL PORTRAIT LENS · 1840 · f/3.6`

### 06 NEGATIVE · 负片 ｜ 0:34–0:39
- 字幕：一张底片，从此可以印出无数张照片。
  *From one negative, countless prints.*
- 画面：白色中浮现拉科克修道院的格子窗，先是明暗反转的负片，再翻转成正片；随后这张照片向四周复制，铺成一面照片墙。
- 标注：`LATTICED WINDOW · LACOCK ABBEY · 1835` / `现存最早的底片` / `CALOTYPE · TALBOT · 1841`
- 转场：照片墙里滑出三张。

### 07 COLOUR · 色彩 ｜ 0:39–0:44
- 字幕：红、绿、蓝三张底片叠在一起，世界第一次有了颜色。
  *Red, green and blue, laid together — and the world had colour.*
- 画面：三张黑白格子缎带底片分别染成红、绿、蓝，从三个方向滑入叠合；叠准的一瞬间出现彩色。HUD 显示三个通道的偏移量归零。
- 标注：`TARTAN RIBBON · J. C. MAXWELL · 1861` / `THREE-COLOUR METHOD · 三色法`

### 08 MOTION · 瞬间 ｜ 0:44–0:49
- 字幕：快门，终于快过了奔马。
  *At last, the shutter outran the galloping horse.*
- 画面：缎带变成胶片条，12 格奔马依次点亮，像西洋镜一样循环播放；四蹄腾空的那一格被圆圈标出。
- 计数器落到 `< 1/2000 s`
- 标注：`THE HORSE IN MOTION · MUYBRIDGE · 1878` / `ALL FOUR HOOVES OFF THE GROUND · 四蹄腾空`

### 09 EVERYONE · 人人 ｜ 0:49–0:54
- 字幕："你只管按下快门，剩下的交给我们。"
  *"You press the button, we do the rest."*
- 画面：一声快门，一格画面裂变成成百上千张带白边的小快照，向外扩散成网。
- 标注：`KODAK No. 1 · 1888` / `100 EXPOSURES · $25`

### 10 PIXEL · 像素 ｜ 0:54–1:00
- 字幕：如今，每年有超过一万亿张照片被拍下。
  *Today, more than a trillion photographs are taken every year.*
- 画面：照片被量化成方形像素块，先是 100×100 的粗马赛克，然后越来越细；镜头拉远，每个像素都是一张照片，铺满画面。
- 计数器切换为 `PIXELS · 像素`：`10 000 → 200 000 000`
- 标注：`S. SASSON · KODAK · 1975` / `100 × 100 PIXELS · 23 s TO RECORD`

### 11 KEEP THE LIGHT · 留住光 ｜ 1:00–1:03.5
- 字幕：从小孔到像素，我们始终在做同一件事：留住光。
  *From pinhole to pixel, we have always done one thing: keep the light.*
- 画面：所有照片化作光点向中心收拢，汇成一束光，呼应第一幕穿过小孔的那束光；光点聚成光圈叶片图形 → 相机闪光全屏白 → **硬切**（配快门声）。

### 12 落版 ｜ 1:03.5–1:08.5
- 相纸白底加细颗粒；背景是镜头对焦环式的同心圆和刻度（`∞ · 10 · 5 · 3 · 2 m`），对应参考片的星图圆环。
- 安全灯红色的光圈图标以 spring 缩放入场，下方横线展开，标题 `光 之 书 写`，副标题 `WRITING WITH LIGHT · c. 400 BCE — TODAY`。
- 去掉电影遮幅，恢复全屏 16:9。

### 13 结尾 ｜ 1:08.5–1:12
- 画面转为暗房的红与黑，粒子光圈再次出现，打字机效果逐字打出 `@一次成像`。

## 3. 设计系统

尺寸按 1080p 计。参考片的 HUD 小字在手机上几乎看不清，本片把最小字号提高到 16px。

| 元素 | 规格 |
|---|---|
| 章节标签 | `—— CAMERA OBSCURA · 小孔成像`，IBM Plex Mono 16px，字距 0.3em，60% 不透明度 |
| 中文字幕 | Noto Sans SC Light 42px，字距 0.08em |
| 英文字幕 | EB Garamond Italic 24px，70% 不透明度 |
| 字幕入场 | 逐字错开 1.5 帧，blur 8px→0、opacity 0→1、y 6px→0；位置在左下、右下、左上之间轮换 |
| HUD 标注 | 圆圈（r=8）+ 引线（stroke-dashoffset 描线）+ 两行等宽字（16px / 14px @50%） |
| 计数器 | 右上角，EB Garamond 64px；数字按千位用细空格分组；标签在上、单位在右 |
| 遮幅 | 第 01–11 章上下各 10%（约 2.25:1），落版时去掉 |
| 胶片颗粒 | 全片叠一层按帧变化的噪点，不透明度 4–6%。既贴合主题，也能避免平涂背景压缩后出现色带（参考片落版就有这个问题） |

| 名称 | 色值 | 用途 |

| 暗房黑 | `#0A0908` | 主背景 |
| 银 | `#C9CCD1` | 银版、银盐颗粒 |
| 沥青棕 | `#8A6A4A` | 日光刻印 |

## 4. 技术方案

```
src/
  Root.tsx            # <Composition id="Main"> 1920×1080 · 30fps · 2160 帧
  Video.tsx           # 按 timeline 排 <Sequence>，叠 Letterbox / Grain / <Audio>
  timeline.ts         # 各章起止帧，唯一的时间来源
  theme.ts            # 色板、字体、字号
  ui/                 # ChapterLabel, Subtitle, Callout, Counter, Letterbox, Grain
  scenes/             # 01Pinhole … 13Outro，每章一个组件
  lib/
    particles.ts      # 种子随机、3D 投影、缓动
    imageToPoints.ts  # 图片 → 点云（用 delayRender 等图片解码完成）
public/
  img/  audio/
```

关键约束与做法：

- **所有动画都是帧号的纯函数**。粒子用 Remotion 的 `random(seed)` 生成，位置由 `f(粒子参数, frame)` 直接算出，不逐帧累加状态，否则并行渲染时会出错。
- **粒子层**用 `<canvas>` 每帧重绘；拖尾就是把同一粒子在 t 和 t−Δ 两个时刻的位置连成线。
- **图片成像**（03、06、07、10）：先把公版照片按亮度采样成点云，粒子从随机位置 spring 插值到目标点。
- **曝光模拟**（04）：画面 = 静态层（建筑 + 擦鞋人）+ 移动粒子层，移动层的不透明度随曝光时长衰减。
- **3D 镜头**（05）：镜片环、光圈叶片、环形文字都用 CSS 3D 变换（`rotateY` + `translateZ`，背面可见，所以环形文字转到背面时呈镜像），光斑用 canvas。效果不够再上 `@remotion/three`。
- **三色合成**（07）：三张灰度图分别染色后用 `mix-blend-mode: screen` 叠加。
- **像素化**（10）：用 canvas 按逐渐缩小的块尺寸重采样。
- **噪点、烟雾**用 `@remotion/noise`（确定性噪声）。
- **渲染**：`npx remotion render Main out/writing-with-light.mp4 --crf=18`。

## 7. 制作步骤

1. **定稿**：确认剧本，核实史实数字（已完成）。
2. **搭框架**：初始化工程，做好设计系统组件，每章先出一张静帧（`npx remotion still`）确认画面风格；同时挑 2–3 首候选配乐给你试听。
3. **做场景**：按风险从高到低：05 镜头 → 04 曝光模拟 → 03 图片点云 → 其余各章。
4. **拼接**：串联转场，配乐对点（drop 对 03 成像，闪光对快门声）。
5. **渲染验收**：检查色带、字幕安全区，并在手机上确认小字可读。
